Quick demo: Run a snippet & paste into Google Sheets

1. Open DevTools

Open Chrome → F12

2. Create Snippet

Sources → Snippets → New

3. Run Snippet

Right-click snippet → Run

When the snippet runs it copies the TSV/text to your clipboard. Open Google Sheets and paste into cell A1 (Ctrl/Cmd+V).

Open repo on GitHub
