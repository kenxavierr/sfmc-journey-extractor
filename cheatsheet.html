SFMC Snippets — Quick Cheat Sheet

Run DevTools Snippets → copy to clipboard → paste into Google Sheets
Repo: github.com/kenxavierr/sfmc-journey-extractor

Which script to use

  • ver1 — Extract Journey Analytics (Email Delivery & Engagement)
  • ver2 — Extract Email Analytics (title, contexts, iframe)
  • ver2-sms — Extract SMS/MMS Analytics (KPIs + table rows)
  • ver3 — Extract Activity Names (one-per-line)

Quick run steps

  1. Open the SFMC page in Chrome and wait until the card is visible.
  2. Press F12 to open DevTools.
  3. Sources → Snippets → New snippet → paste the chosen .js file.
  4. Save (Ctrl/Cmd+S) → Right-click snippet → Run.
  5. Alert confirms copy. Paste into Google Sheets (cell A1).
If the content is inside an iframe: use the Console context selector (top-left) or open the iframe src in a new tab.

Paste into Google Sheets

  1. Open a blank sheet and select cell A1.
  2. Paste (Ctrl/Cmd+V). Tabs will split into columns automatically.
  3. If everything lands in one column: Data → Split text to columns → Separator: Tab.

Quick troubleshooting

  • No analytics card found: wait 2s and re-run; switch to iframe context.
  • Copy fails: open DevTools Console and copy logged TSV manually.
  • Need full files? Download snippets from the repo and add as Snippets.
